# 👨‍🏫 TEACHER TRAINING GUIDE - Academy Recording System

## 📖 What This System Does

This system automatically records your teaching sessions and saves them to the admin's laptop. You don't need to worry about storage on your laptop - everything is saved centrally!

---

## 🚀 DAILY USAGE - SIMPLE 3 STEPS

### **STEP 1: START YOUR DAY (Morning)**

1. **Turn on your laptop**

2. **Find the "Academy Recording" icon** on your desktop
   - It looks like a shortcut file

3. **Double-click it**
   - Chrome will open automatically
   - You'll see the recording page

4. **Enter your Teacher ID**
   ```
   Example: teacher-01, teacher-02, etc.
   (Admin will tell you your ID)
   ```

5. **Keep "Record microphone" checked** ✅

6. **Click "Start Recording"** button

7. **Chrome will ask what to share:**
   ```
   ○ Entire screen (select this to record everything)
   ○ Window (select specific app)
   ○ Chrome Tab (for web-based teaching)
   ```

8. **Select what you want to record** and click "Share"

9. **Check the status:**
   - Should say: "Recording locally..." or "Recording microphone..."
   - Timer starts: 00:00:00
   - Chunks counter increases

10. **Minimize Chrome** (don't close!)
    - Click the minimize button (—)
    - Chrome runs in background
    - Recording continues

11. **Start teaching!** 🎓

---

### **STEP 2: DURING THE DAY**

✅ **DO:**
- Continue teaching normally
- Use your laptop as usual
- Let Chrome run in background
- Your laptop can go to sleep (will wake up automatically)

❌ **DON'T:**
- Close the Chrome tab
- Close Chrome browser
- Sign out of Windows
- Shut down laptop
- Turn off Wi-Fi

💡 **TIP:** If you accidentally close Chrome, just run "Academy Recording" again from desktop and restart recording.

---

### **STEP 3: END YOUR DAY (Evening)**

1. **Open Chrome** (if minimized)

2. **Go to the recording tab**

3. **Click "Stop Recording"** button

4. **Wait for status to show:**
   ```
   Status: Stopped
   Pending uploads: 0  ← Wait for this to be 0!
   ```

5. **Once pending = 0, you can:**
   - Close Chrome
   - Shut down your laptop
   - Go home! 🏠

## 🎥 HOW IT WORKS (Simple Explanation)

```
Your Laptop                Admin Laptop
┌──────────┐              ┌──────────┐
│          │              │          │
│ Recording│ ─ Upload ──► │  Server  │
│          │   every      │          │
│  Chrome  │  5 seconds   │ External │
│          │              │   HDD    │
└──────────┘              └──────────┘
```

**Every 5 seconds:**
- Your laptop sends recording data to admin's laptop
- Admin's laptop saves it to external hard drive
- **Nothing is saved on your laptop!**

**Every 30 minutes:**
- One recording file is completed
- A new file starts automatically
- You don't need to do anything!

## ❓ COMMON QUESTIONS

### **Q: Will this slow down my laptop?**
**A:** No! Recording uses only 15-30% CPU. You can use other programs normally.

### **Q: What if my internet disconnects?**
**A:** The system will retry uploads automatically when internet returns. Keep Chrome open!

### **Q: Can I use other programs while recording?**
**A:** Yes! Recording runs in background. Use your laptop normally.

### **Q: What if I accidentally close Chrome?**
**A:** Don't panic! Just:
1. Run "Academy Recording" again from desktop
2. Enter your teacher ID
3. Click "Start Recording"
4. Continue teaching

The old recording is saved. You'll start a new one.

### **Q: How do I know it's working?**
**A:** Check these signs:
- Timer is counting: 00:15:23
- Chunks counter increases
- Status says "Recording..."

### **Q: What if there's a problem?**
**A:** Contact the admin immediately. Don't try to fix it yourself!

## 🚨 TROUBLESHOOTING

### **Problem: "Cannot connect to server"**

**What it means:** Your laptop can't reach admin's laptop

**Solution:**
1. Check if you're on academy Wi-Fi
2. Ask admin: "Is the server running?"
3. Try restarting Chrome

### **Problem: "Chunks not uploading"**

**What it means:** Network issue

**Solution:**
1. Check Wi-Fi connection
2. Ask: "Is anyone else having this issue?"
3. Contact admin

### **Problem: "Microphone not working"**

**What it means:** Chrome doesn't have microphone permission

**Solution:**
1. Click the padlock 🔒 in Chrome address bar
2. Find "Microphone"
3. Change to "Allow"
4. Refresh page
5. Start recording again

### **Problem: "Screen is black in recording"**

**What it means:** Wrong screen/window selected

**Solution:**
1. Stop recording
2. Start again
3. This time, select "Entire screen" instead of window
