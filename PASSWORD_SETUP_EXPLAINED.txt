┌──────────────────────────────────────────────────────────────────────────────┐
│ WHY YOU NEED TO SET PASSWORDS IN 2 FILES                                    │
└──────────────────────────────────────────────────────────────────────────────┘

Think of it like a lock and key:

    CHROMEBOOK (Client)                    ADMIN LAPTOP (Server)
    ═══════════════════                    ═════════════════════
    
    🔑 Has the KEY                         🔒 Has the LOCK
    (password in app.js)                   (password in server)
    
    When uploading:                        Server checks:
    "Here's my password!"      ─────►      "Does it match mine?"
                                           
    If MATCH:    ✅ Allow upload
    If NO MATCH: ❌ Reject (Unauthorized)


┌──────────────────────────────────────────────────────────────────────────────┐
│ WHERE TO SET PASSWORDS                                                       │
└──────────────────────────────────────────────────────────────────────────────┘

FILE 1: start-admin-server.bat (on Admin Laptop)
════════════════════════════════════════════════

Location: C:\chromebook-recorder\start-admin-server.bat

Open with Notepad, find this line:

    set UPLOAD_PASSWORD=academy2024

Change to your password:

    set UPLOAD_PASSWORD=MySecret2024!
                        ↑↑↑↑↑↑↑↑↑↑↑↑↑↑
                        YOUR PASSWORD HERE


FILE 2: public\app.js (on Admin Laptop, used by Chromebooks)
═════════════════════════════════════════════════════════════

Location: C:\chromebook-recorder\public\app.js

Open with Notepad, find LINE 2:

    const UPLOAD_PASSWORD = 'CHANGE_ME_IN_PRODUCTION';

Change to THE SAME password:

    const UPLOAD_PASSWORD = 'MySecret2024!';
                             ↑↑↑↑↑↑↑↑↑↑↑↑↑↑
                             SAME PASSWORD!

│ HOW IT WORKS WHEN RECORDING                                                  │
└──────────────────────────────────────────────────────────────────────────────┘

1. Teacher clicks "Start Recording" on Chromebook
2. After 30 minutes, recording is ready to upload
3. Chromebook sends file + password to admin laptop:

    Chromebook:
    ┌─────────────────────────────────────┐
    │ Here's my recording!                │
    │ My password is: SecurePass123!      │
    └──────────────┬──────────────────────┘
                   │
                   │ HTTPS (encrypted)
                   ↓
    Admin Laptop:
    ┌─────────────────────────────────────┐
    │ Checking password...                │
    │ My password is: SecurePass123!      │
    │                                     │
    │ ✅ MATCH! → Save file               │
    └─────────────────────────────────────┘


If passwords DON'T match:

    Chromebook:
    ┌─────────────────────────────────────┐
    │ Here's my recording!                │
    │ My password is: WrongPassword       │
    └──────────────┬──────────────────────┘
                   │
                   │ HTTPS (encrypted)
                   ↓
    Admin Laptop:
    ┌─────────────────────────────────────┐
    │ Checking password...                │
    │ My password is: SecurePass123!      │
    │                                     │
    │ ❌ NO MATCH! → Reject upload        │
    │ Show error: "Unauthorized"          │
    └─────────────────────────────────────┘


┌──────────────────────────────────────────────────────────────────────────────┐
│ WHY THIS IS IMPORTANT                                                        │
└──────────────────────────────────────────────────────────────────────────────┘

Without passwords:
    ❌ Anyone on Wi-Fi could upload fake recordings
    ❌ No security
    ❌ Unauthorized access

With matching passwords:
    ✅ Only authorized devices can upload
    ✅ Secure system
    ✅ Protected from unauthorized access


┌──────────────────────────────────────────────────────────────────────────────┐
│ CHECKLIST: VERIFYING PASSWORDS MATCH                                         │
└──────────────────────────────────────────────────────────────────────────────┘

1. Open start-admin-server.bat
   Look for: set UPLOAD_PASSWORD=__________
   Write down the password: ________________

2. Open public\app.js (line 2)
   Look for: const UPLOAD_PASSWORD = '__________';
   Write down the password: ________________

3. Compare:
   Are they EXACTLY the same? (including capitals, symbols, etc.)
   
   ✅ YES → Good! Passwords match!
   ❌ NO  → Fix them! They must be identical!

4. After changing, restart server:
   - Close CMD window (Ctrl+C)
   - Run start-admin-server.bat again


┌──────────────────────────────────────────────────────────────────────────────┐
│ COMMON MISTAKES                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

❌ WRONG: Different passwords
────────────────────────────
File 1: set UPLOAD_PASSWORD=password123
File 2: const UPLOAD_PASSWORD = 'Password123';
                                  ↑
                        Capital P - different!

✅ CORRECT: Same passwords
────────────────────────────────
File 1: set UPLOAD_PASSWORD=Password123
File 2: const UPLOAD_PASSWORD = 'Password123';
                        Both exactly the same!


❌ WRONG: Missing quotes in app.js
────────────────────────────────────
const UPLOAD_PASSWORD = Password123;  ← Missing quotes!

✅ CORRECT: Quotes in app.js
────────────────────────────────────
const UPLOAD_PASSWORD = 'Password123';  ← Has quotes!


❌ WRONG: Extra spaces
────────────────────────
set UPLOAD_PASSWORD= Password123   ← Space before password
const UPLOAD_PASSWORD = ' Password123';  ← Space in quotes

✅ CORRECT: No extra spaces
────────────────────────────────────
set UPLOAD_PASSWORD=Password123
const UPLOAD_PASSWORD = 'Password123';


┌──────────────────────────────────────────────────────────────────────────────┐
│ TESTING IF PASSWORDS WORK                                                    │
└──────────────────────────────────────────────────────────────────────────────┘

STEP 1: Start server
────────────────────
    cd C:\chromebook-recorder
    start-admin-server.bat

STEP 2: Test from Chromebook
─────────────────────────────

    2. Start recording
    3. Wait 30 seconds (or wait for 30-minute segment)

        ❌ Server shows: "Unauthorized upload attempt"
