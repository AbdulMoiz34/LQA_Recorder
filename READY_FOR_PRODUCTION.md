### **📋 Quick Start Steps**

1. **Configure Passwords** (5 min)
   - Edit `start-admin-server.bat`
   - Edit `public/app.js`
   - Match passwords exactly

2. **Setup Admin Laptop** (25 min)
   - Connect external HDD
   - Configure static IP
   - Generate SSL certificates
   - Start server

3. **Test Locally** (10 min)
   - Open `https://localhost:3443`
   - Test recording
   - Verify file on external HDD

4. **Deploy to Chromebooks** (1 hour)
   - Create bookmarks
   - Train 3 pilot teachers
   - Monitor for 1 week

5. **Full Rollout** (3 days)
   - Train remaining teachers
   - Monitor closely
   - Go live!
